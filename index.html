Häufig gestellte Fragen

Was passiert, wenn ich ein Roaming-Paket aufgebraucht habe?⌄
Sobald Ihr Paket aufgebraucht ist, wird das Roaming blockiert. Sie können im Roaming Cockpit ein neues Paket kaufen.
Was passiert, wenn ich mein im Abo inkludiertes Datenvolumen aufgebraucht habe?⌄
Das Daten-Roaming wird gesperrt. Für die entsprechende Zone können Sie im Roaming Cockpit ein zusätzliches Paket kaufen.
Was ist die Quickline Travel eSIM?⌄
Die Quickline Travel eSIM ist eine separate eSIM-Lösung für mobile Daten auf Reisen und ergänzt die klassischen Quickline Roaming-Pakete.
